Lab App — Equipamentos

Integrante: João Vitor de Souza Costa

Backend (rodar):

- cd backend
- bun install
- bun run dev

Frontend: abra `frontend/index.html` com Live Server (VS Code).

Rotas principais:
- GET /equipamentos
- GET /equipamentos/:id
- POST /equipamentos  (body: {nome,tipo,status,descricao?})
- PUT /equipamentos/:id
- DELETE /equipamentos/:id
